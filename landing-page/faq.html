TLDR;esume FAQs

Is this really free?

Yes. You don't need to create an account, give any of your personal information, upload anything to this site, or create a subscription. You don't even need to sign up for a mailing list.

This is 'free as in beer', no strings attached. I hope it's helpful.

How is the security of my data handled?

The web app asks you for a folder on your computer where all data can be saved. That folder is where your resume lives, as well as all of the customized resumes, cover letters, and metadata the app generates. Nothing goes to the cloud for storage or a server controlled by me.

The only time API calls are made are to the AI provider you choose to use. You've got two choices here: Anthropic (who makes Claude) and OpenAI (who makes ChatGPT). During onboarding I'll give you instructions on how to get an API key for either service. You will need to pay for the API access you use, but it will be very cheap. Even with the most expensive model, you can have a full customized resume and cover letter for less than $0.50 (at least that's what I've personally found). The less expensive models will do the same thing for $0.05.

Why do I have to use Chrome?

Chromium-based browsers (Google Chrome, Edge, Brave, Dia, Vivaldi, Arc, etc.) have a "File system access API" specifically for working with files on your local computer. Unfortunately Firefox and Safari don't have this. If you don't have a Chromium-based browser already, I recommend Brave.

I know this isn't the way most apps work today. Usually someone has an idea for an app like this and they want to set up a subscription around it, charge you, etc. Monthly Recurring Revenue! Tech millionaire! (Which is funny, because tech founders generally want to be billionaires, not millionaires, but I digress.)

It's not that I don't want to make a living. I started this after some close friends were laid off and I wanted to do something to help them. I hope it helps them, and that maybe it can help you (or someone you know who is looking for a job) too.

Why doesn't this work on my phone?

The security model I chose is to keep all of your data on your computer's filesystem. I don't want to have it on a server somewhere that I have control of (and frankly I don't want to pay for that server!) An application like this could absolutely run on a phone if it is cloud hosted, but TLDR;esume is not.

Sorry. You get what you pay for, bwahaha! 😈

Trust AI? Surely you're crazy!

I probably am, and don't call me Shirley! 🥁

My personal experience with AI is that it's a great tool when you're using it the right way. One of the keys to having good outcomes with AI tools is having excellent context.

What we're trying to do here is provide good context on several levels by having an optimized base resume, a very clear job description that you're applying for, and a chance for you to fill in gaps through the Q and A section. It allows the AI to have lots of good context that it can use to generate the content for you.

But the best context comes from you. Make sure you always review everything, and at every step, there's always a way for you to edit what's been output so that you can put your own spin on things, correct errors, and make this your own. This is a tool to get you from zero to one and help you overcome the hard initial work of starting. It's not supposed to carry you all the way to the finish line on its own. You're going to need to do the work for that part!
